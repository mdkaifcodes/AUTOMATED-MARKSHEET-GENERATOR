📊**Automated Marksheet Generator**
A robust Python and Pandas-based console application designed to automate student result processing, grade evaluation, and formatted marksheet generation from CSV records.
🚀**Key Features**
Fast CSV Ingestion: Automatically reads and processes student data from marks.csv using the Pandas library.
Strict Input Validation: Validates that all subject marks fall within the valid range of 0 to 100, skipping invalid rows with warning logs.
Automated Computation: Computes total marks (out of 300) and calculates precise percentages.
Smart Grading & Status Evaluation:
Assigns letter grades (A+ to F) based on the percentage scale.
Evaluates PASS/FAIL status.
Interactive Console Menu: Clean command-line interface to look up individual student marksheets via Roll Number.
🛠️**Tech Stack**
Language: Python 3
Data Manipulation: Pandas Library
